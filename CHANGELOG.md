# CHANGELOG - MateAPP

Todos los cambios importantes del proyecto serán documentados en este archivo.

## [1.0.0] - 2026-06-09

### Agregado
- Sistema de autenticación de usuarios con JWT
- Interfaz de login responsiva y validación de formularios
- Módulo de ejercicios matemáticos con generación aleatoria
- Sistema de niveles de dificultad (fácil, medio, difícil)
- Pantalla principal de inicio con bienvenida al usuario
- Enrutamiento con AngularJS para navegación fluida
- Servicio de autenticación centralizado
- Controladores para login, home y ejercicios

### Mejorado
- Diseño visual moderno y consistente
- Estilos responsive para todos los dispositivos
- Validación de datos mejorada
- Mensajes de error personalizados
- Estructura de carpetas organizada
- Documentación del proyecto

### Corregido
- Error de validación de email
- Problema de responsividad en dispositivos móviles
- Inconsistencias en estilos CSS
- Manejo de errores en formularios

### Seguridad
- Validación de contraseñas fortalecida
- Tokens de sesión con expiración
- Protección contra inyección de código
