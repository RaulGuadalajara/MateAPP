# Historial de Commits - MateAPP

## Documentación de Commits Descriptivos

Este archivo documenta los commits realizados en el proyecto MateAPP con mensajes claros y descriptivos.

### Estructura de Mensajes de Commit

Cada commit sigue el formato:
```
[TIPO] Descripción breve clara y concisa

- Detalle 1 del cambio
- Detalle 2 del cambio
```

### Tipos de Commits
- **feat**: Nueva funcionalidad
- **fix**: Corrección de bugs
- **refactor**: Refactorización de código
- **docs**: Cambios en documentación
- **style**: Cambios de estilos CSS/HTML
- **chore**: Tareas de mantenimiento

---

## Registro de Cambios Implementados

- Creación del servicio de autenticación (authService.js)
- Validación de credenciales de usuario
- Gestión de tokens de sesión

### 2. feat: Desarrollar interfaz de login responsiva
- Diseño de formulario de inicio de sesión

### 4. style: Mejorar estilos visuales de la aplicación
- Consistencia de paleta de colores

- Configuración de módulo AngularJS

- Manejo de redirecciones

### 6. feat: Agregar pantalla de inicio con bienvenida
- Diseño de panel principal

### 7. fix: Corregir validación de formularios
